# Fernando — Estrategia de marca

Sitio tipo blog para Fernando, estratega de marca. Landing editorial con hero, artículo destacado, archivo filtrable por categoría, sección "sobre mí" y captura de newsletter.

## Estructura
- `index.html` — sitio completo (HTML + CSS + JS en un solo archivo, sin dependencias de build).

## Uso
Abrir `index.html` directamente en el navegador, o servir la carpeta con cualquier servidor estático (GitHub Pages, Netlify, Vercel, etc.).
