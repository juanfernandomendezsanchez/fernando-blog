# Fernando — Estrategia de marca

Sitio tipo blog para Fernando, estratega de marca. Landing editorial con hero, pilares de contenido, blog en construcción, formulario de diagnóstico y captura de newsletter.

## Estructura
- `index.html` — sitio completo (HTML + CSS + JS en un solo archivo, sin dependencias de build).
- `apps-script/Code.gs` — backend del formulario de diagnóstico: Google Apps Script + Google Sheets + Gmail. Coste $0.
- `apps-script/SETUP.md` — guía paso a paso para desplegar el backend en tu propia cuenta de Google.

## Uso
Abrir `index.html` directamente en el navegador, o servir la carpeta con cualquier servidor estático (GitHub Pages, Netlify, Vercel, etc.).

Para que el formulario "Agendar diagnóstico" funcione de verdad, sigue `apps-script/SETUP.md` — toma unos 10 minutos y no requiere ningún servicio de pago.
